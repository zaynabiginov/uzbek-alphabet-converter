# Uzbek Alphabet Converter — руководство пользователя

Uzbek Alphabet Converter — бесплатное веб-приложение для преобразования
узбекского текста между кириллицей, новой латиницей и латиницей с апострофами.
Можно вводить текст прямо на странице или загружать документы. Конвертация
выполняется локально в браузере: файлы не отправляются на сервер.

## Возможности

- Преобразование текста и поддерживаемых документов между тремя письменностями.
- Копирование результата или скачивание текста в UTF-8-файле `.txt`.
- До 15 файлов за один запуск, размер каждого — не более 200 МБ.
- Скачивание каждого успешного результата отдельно или всех результатов одним
  ZIP-архивом.
- Интерфейс на узбекском и русском языках; светлая, тёмная и системная темы.
- Краткий просмотр результата и отображение ошибок для отдельных файлов.

## Письменности

Конвертация меняет письменность, но не переводит текст. Перед запуском выберите
исходный алфавит и желаемый алфавит результата:

1. **Узбекская кириллица** — например, `Ўзбекистон`.
2. **Новая узбекская латиница** — `Ö` и `Ğ` для `Oʻ` и `Gʻ`, `Ş` и `Ç` для
   `Sh` и `Ch`; например, `Oʻzbekiston` → `Özbekiston`.
3. **Узбекская латиница с апострофами** — формы `O'`, `G'`, `Sh` и `Ch`;
   например, `O'zbekiston`.

При преобразовании из кириллицы сохраняется регистр букв. При обратном
преобразовании распознаются сочетания `oʻ/gʻ`, `sh`, `ch`, `shch`, `yo`, `yu`,
`ya` и `ts`; поддерживаются разные символы апострофа. Перед использованием
проверьте результат: автоматическая конвертация не заменяет проверку орфографии
и перевод.

## Поддерживаемые файлы

| Формат | Результат | Примечания |
| --- | --- | --- |
| `.txt` | `.txt` | Текст UTF-8 обрабатывается частями; большие файлы могут требовать больше времени и памяти. |
| `.doc` | `.doc` | Текст извлекается и записывается в совместимый с RTF документ Word. Исходное форматирование, структура таблиц и изображения не сохраняются. |
| `.docx` | `.docx` | Преобразуется текст основного документа, колонтитулов, сносок и концевых сносок; структура архива сохраняется. |
| `.xlsx` | `.xlsx` | Преобразуется текст, найденный в XML-частях книги Excel. |
| `.pptx` | `.pptx` | Преобразуется текст, найденный в XML-частях презентации PowerPoint. |
| `.pdf` | `.pdf` | Страницы с доступным для выделения текстом превращаются в изображения; текст приблизительно перерисовывается. |

### Ограничения

- Устаревшие форматы `.xls` и `.ppt` не поддерживаются.
- Сканированные PDF без текстового слоя для выделения текста обработать нельзя.
- Итоговый PDF состоит из изображений: текст нельзя выделить и скопировать;
  ссылки, формы и некоторые детали оформления могут не сохраниться.
- Положение текста в PDF восстанавливается приблизительно, поэтому шрифты,
  интервалы и размещение могут отличаться от оригинала.
- Для старых файлов `.doc` исходное оформление не сохраняется; результатом
  будет текстовый документ Word, совместимый с RTF.
- Защищённые паролем документы Office и архивы Office в формате ZIP64 не
  поддерживаются. Если распакованный размер архива Office превышает 500 МБ,
  файл отклоняется.
- Обработка больших файлов требует дополнительной памяти устройства. Не
  закрывайте страницу до завершения конвертации.

## Запуск

Это статический сайт: сборка и установка пакетов не требуются. PDF- и
DOC-парсеры включены в репозиторий и не загружаются со стороннего CDN. Для
корректной загрузки JavaScript-модулей рекомендуется запускать сайт по HTTP.

1. Склонируйте репозиторий или скачайте его архив:

   ```sh
   git clone https://github.com/zaynabiginov/uzbek-alphabet-converter.git
   cd uzbek-alphabet-converter
   ```

2. Запустите локальный HTTP-сервер из папки проекта. Например, с Python 3:

   ```sh
   python -m http.server 8000
   ```

   В Windows в PowerShell или командной строке можно использовать эту же
   команду. Если команда `python` не найдена, попробуйте
   `py -m http.server 8000`.

3. Откройте в браузере <http://localhost:8000>.

## Использование

### Конвертация текста

1. Выберите исходную письменность и письменность результата.
2. Введите или вставьте текст в левое поле.
3. Нажмите **«Конвертировать текст»**.
4. Проверьте результат справа. Нажмите **«Скопировать»** или скачайте его
   кнопкой **«Скачать TXT»**.

### Конвертация файлов

1. Выберите направление конвертации.
2. Нажмите **«Выбрать файл»** или перетащите файлы в область загрузки.
3. Выберите поддерживаемые файлы размером до 200 МБ каждый; за один раз можно
   обработать не более 15 файлов.
4. Нажмите **«Конвертировать»**. Файлы обрабатываются по очереди; успешные
   результаты и ошибки отображаются в списке.
5. Скачайте результаты по отдельности или объедините все успешные результаты в
   ZIP-архив.

## Конфиденциальность и лицензии

Текст и файлы обрабатываются в браузере пользователя и не отправляются на сервер
для конвертации. При размещении сайта в интернете сам сайт и его ресурсы
загружаются из вашего хостинга.

Встроенный PDF.js распространяется по лицензии Apache License 2.0, а парсер
старого формата DOC — по лицензии MIT. Полные тексты лицензий и сведения об
исходном коде находятся в соответствующих каталогах `vendor`.
